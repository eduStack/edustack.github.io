# eduStack Historical Blog

This branch preserves 184 articles dated 2014-2020 and the original static assets.
The site was generated by Hugo; the full Hugo source project is not in this branch.

## Publication

- GitHub Pages source: `master`, repository root.
- Archive domain: `https://archive.edustack.org/`.
- DNS: CNAME `archive` -> `edustack.github.io` (DNS only during setup).
- After DNS resolves, set the Pages custom domain and enable HTTPS once its certificate is ready.
- The current website will use `https://www.edustack.org/` separately.
- No redirects from historical article URLs on the main domain are required.

Archive navigation, canonical URLs, RSS and sitemap use the archive domain.
Historical article paths and assets remain unchanged. The archive notice links to
the current website. Existing article attribution and license notices are preserved.

Migration changes must be deployed only after the archive DNS record is ready.
